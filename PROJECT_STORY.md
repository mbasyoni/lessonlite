# LessonLite
## Tagline
Your lesson notes, shaped into a study pack you can use offline.

## The learning barrier
A learner may have notes but still need a simpler, more readable way to revisit them. An account, continuous connection or complex learning platform can create extra friction. LessonLite focuses on the small step between receiving notes and having a personal study pack.

## What it does
Paste lesson notes, select a source paragraph, and write a question and answer. Organize cards with optional section names and key terms. Reveal each answer when ready, check its attached source, and see which paragraphs you have used. Choose a larger reading size or higher contrast, then download a standalone HTML study pack or print its answer key. Save the editable project if you want to continue later.

## What is different
LessonLite does not invent explanations or hide the source behind generated summaries. The learner or educator writes the cards. Every card keeps a clear path back to the selected paragraph. The exported pack needs no account, service or application installation.

## Built during the event
The application, synthetic example, tests and documentation were created from scratch on 30 October 2026. OpenAI assisted with design, coding, testing and documentation. No commercial ImpedanceIQ code, datasets or research engines were reused. Runtime dependencies: none. MIT-licensed application source is included.

## Inclusive design
Semantic headings and form labels, visible keyboard focus, native answer disclosure controls, adjustable text size, a contrast option, responsive layout, and offline/print delivery. These are implemented features, not a claim of complete accessibility conformance or demonstrated educational effectiveness. Screen-reader and learner studies remain future work.

## Demonstration outline
1. Open the synthetic water-cycle lesson.
2. Reveal its first answer and attached source with the keyboard.
3. Select another paragraph, write a question and answer, and add the card.
4. Increase text size and contrast.
5. Download and open the offline HTML pack.
6. Save/reopen the editable project; show that source replacement needs confirmation.

## Scope
No automatic answer generation, grading, translation, learner accounts or private learner data. The example is synthetic. No user study is claimed.
